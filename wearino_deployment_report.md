## 🚀 Step-by-Step Deployment Guide

### 1. Database Migration (Neon.tech)
*   **Sign up:** Create a free account on [Neon.tech](https://neon.tech/).
*   **Project Creation:** Create a new project named `wearino`.
*   **Connection String:** Copy the `DATABASE_URL` (looks like `postgres://user:pass@ep-hostname.aws.neon.tech/neondb`).
*   **Data Import:** Export your local Postgres data and run the SQL script against the Neon database using the Neon Console or `psql`.

### 2. Backend Deployment (Render.com)
*   **GitHub Integration:** Push your project to a GitHub repository.
*   **Create Web Service:** In Render, create a new "Web Service" and link your repository.
*   **Root Directory:** Set to `backend` (or the folder containing `index.js`).
*   **Build Command:** `npm install`
*   **Start Command:** `node index.js`
*   **Environment Variables:**
    *   `DATABASE_URL`: Your Neon connection string.
    *   `JWT_SECRET`: A strong random string.
    *   `PORT`: `5001` (or your preferred port).
    *   `NODE_ENV`: `production`

### 3. Frontend Deployment (Vercel)
*   **Sign up:** Create a free account on [Vercel.com](https://vercel.com/).
*   **Import Project:** Link your GitHub repository.
*   **Framework Preset:** Select `Next.js`.
*   **Root Directory:** Set to `frontend`.
*   **Environment Variables:**
    *   `NEXT_PUBLIC_API_URL`: The URL provided by Render (e.g., `https://wearino-backend.onrender.com/api`).
*   **Deploy:** Vercel will build and assign a `.vercel.app` domain with free SSL.

### 4. Media Persistence Strategy
> [!IMPORTANT]
> Because Render and Vercel use "Ephemeral" storage, any new images uploaded by users will be deleted when the server restarts. 
> 
> **Zero-Cost Fix (No Code Change):** 
> 1. Commit all current images in the `uploads/` folder to your GitHub repository.
> 2. When you deploy, Render will serve these images from the "baked-in" folder.
> 
> **Long-term Fix (Recommended):**
> Integrate the Cloudinary API. This allows uploads to persist forever on their free tier.

## ⚠️ Free Tier Limitations

1.  **Server Sleeping:** Render's free tier spins down after 15 minutes of inactivity. The first visitor will experience a "cold start" delay of ~30 seconds.
2.  **Database Storage:** Neon's free tier is limited to 0.5GB. This is sufficient for thousands of products but monitor your usage.
3.  **Vercel Bandwidth:** The free tier includes 100GB of bandwidth per month, which is plenty for a starting business.
